# DesignSpark

Платформа вдохновения для дизайнеров: лента референсов, поиск с фильтрами, коллекции, тренды, уведомления и мини-игра.
Учебный проект по проектной карте UX.

## Возможности

- регистрация, вход, восстановление пароля (демо)
- лента работ в стиле Pinterest с бесконечной прокруткой
- поиск по названию, типу, стилю, цвету и дате, сортировка
- лайки, комментарии, подписки, уведомления
- коллекции с экспортом в PDF (печать браузера)
- загрузка своих работ со сжатием в WebP
- светлая и тёмная темы, мини-игра «Найди пару»

## Запуск

Сборка не нужна: откройте `index.html` в браузере или поднимите любой статический сервер.

```bash
npx serve .
```

Данные (аккаунты, лайки, коллекции) сохраняются в `localStorage` браузера.

## Структура

```
index.html            разметка и подключение скриптов
css/
  fonts.css           подключение шрифтов
  base.css            переменные, сброс, типографика
  components.css      шапка, кнопки, карточки, формы, сетка
  pages.css           формы с мозаикой, превью-лента, игра
js/
  config.js           настройки (Supabase, необязательно)
  utils.js            вспомогательные функции
  data.js             справочники и список работ
  store.js            состояние и localStorage
  ui.js               карточки, сетка, тосты, тема, навигация
  pages/              страницы: главная, поиск, работа, загрузка, профиль, коллекции, вход, уведомления, игра
  actions.js          обработчики кликов и форм
  router.js           маршрутизация и шапка
assets/
  fonts/              Onder, Montserrat
  images/works/       изображения работ
  logo.svg
```

## Общие аккаунты (необязательно)

1. Создайте проект на [Supabase](https://supabase.com) и включите вход по email.
2. В `js/config.js` укажите `url` и `key` (anon key).

Тогда регистрация и вход будут работать на всех устройствах. Работы и коллекции по-прежнему хранятся в браузере.

## Деплой

GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)`.
